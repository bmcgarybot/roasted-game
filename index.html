How to Play

4-10 players. One device. Zero mercy.

1. Each round, one player is the TARGET.

2. Everyone else gets cards. Pick one SETUP (black) + one PUNCH (red).

3. Optional: play a WILD (gold) card for chaos.

4. Target reads each combo aloud. Everyone votes funniest.

5. Winner = 😭 Tear of Laughter. Target = 🛋️ Therapy Token.

6. First to 5 Tears wins! 3 Therapy Tokens = pity prize.

Wild Cards:

⚡ Double Tap — play TWO punches

💀 Group Roast — everyone attacks

🔄 Reverse Roast — target roasts back

🪞 You Wish — target self-roasts

🎯 Make It Personal — use their name
